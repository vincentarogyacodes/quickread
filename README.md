# What is QuickRead?

QuickRead is an AI-powered web application that accepts web article URL and returns a bulleted summary. It enables you to understand long walls of text in under a minute and helps you decide if the article is worth your time before committing to read it.

QuickRead came from a simple, real-world problem, when a friend of my decided not to read a lengthy web article due to lack of structure and information overload. QuickRead exists to alleviate that friction.

``` URL  →  Article Extraction  →  AI Summarization  →  Clean Summary ```

## A note on this project

QuickRead is both a real, working application and learning project. It's built from the ground up and it includes frontend, backend, API design, error handling, documentation, and version control. QuickRead is also my hands on approach to develop full-stack development skills alongside building a portfolio of technical documentation.

The codebase and the README is reflection of the project's current status, not a finished, idealized version. Known limitations, edge cases, future features are documented below.

## Features

- 📎 **Paste any web URL**: containing an article to receive a clean, structured, and readable summary.
- 🧠 **AI-Powered Summarization**: Receive a concise article overview and key facts as scannable bullets.
- 🚦 **Layered Validation**: Client-side input checks and server-side request validation and error handling.
- 🖥 **Markdown Rendering**: Properly formatted headers and bullets.
